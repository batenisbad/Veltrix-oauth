Usage personnel — Sandbox

Cette page décrit le retour OAuth statique et le fonctionnement local F3 actuellement documenté. Elle ne constitue pas une déclaration de conformité juridique ou une approbation Production.

Données de connexion OAuth

eBay redirige le navigateur vers une adresse HTTPS pouvant contenir un code temporaire et un état de session (state). Le JavaScript des pages de retour garde l’adresse initiale en mémoire, nettoie l’adresse courante et permet sa copie uniquement sur clic. Il ne montre pas le code ni le state. Il ne les écrit pas dans un stockage navigateur, cookie ou fichier et ne les transmet pas à un autre serveur.

Les références mémoire sont abandonnées après copie réussie, sortie de page ou expiration locale (cinq minutes au maximum, éventuellement moins). Cela ne garantit pas l’effacement physique de la mémoire ni l’annulation d’une copie déjà autorisée par le navigateur.

Application Windows

Après collage volontaire, VELTRIX vérifie l’adresse et l’état de session. F3 utilise le coffre d’identifiants Windows pour la configuration et les jetons vendeur, séparés entre Sandbox et Production, sans repli en fichier clair pour ces jetons. L’application utilise également une base locale pour ses données produit ; ces pages n’y accèdent pas. Le mot de passe eBay se saisit chez eBay, pas sur ces pages.

La déconnexion locale retire les jetons de l’environnement concerné ; elle ne révoque pas l’autorisation distante eBay. Aucune durée générale de conservation des données de l’application n’est définie ici.

GitHub Pages et navigateur

GitHub Pages et son infrastructure reçoivent la requête initiale, y compris ses paramètres OAuth, avant l’exécution du nettoyage. L’existence et la durée de conservation de journaux contenant ces paramètres ne sont pas vérifiées ni contrôlées par cette page. Le nettoyage ne supprime pas ces éventuelles traces.

Le navigateur, ses extensions, une restauration de session, les outils de diagnostic, ainsi que le presse-papiers Windows, son historique ou sa synchronisation peuvent conserver des informations. La page ne lit pas votre presse-papiers et n’en efface pas l’historique. La durée et les réglages de ces systèmes ne sont pas fixés par VELTRIX.

Données non collectées par les pages

Le code de ces trois pages ne comporte ni télémétrie, ni analytics, ni publicité, ni ressource externe, ni formulaire de collecte, ni lecture d’identifiants Windows. Il ne collecte pas de commandes ou données de paiement. Cela ne signifie pas que l’hébergeur ne reçoit aucune donnée technique de navigation.
